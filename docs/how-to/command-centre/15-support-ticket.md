# Command Centre: Open a support ticket

**Where:** **Support** → `/support`

![Support](../../screenshots/app/support.png)

---

## Process flow

```mermaid
flowchart TD
  A[New ticket] --> B[Subject, priority, category, body]
  B --> C[Submit]
  C --> D[Staff replies from staff portal]
  D --> E[You get email updates · if SMTP configured]
  E --> F[Close when resolved]
```

---

## Steps

1. Open **Support**.
2. Create ticket with clear subject and steps to reproduce.
3. Attach context (org slug, job id, screenshot).
4. Watch for staff replies.
5. Close or reopen as needed.
