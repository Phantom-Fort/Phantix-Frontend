## What you need during setup (checklist)

| # | Item | Required? | Doc |
|---|------|-----------|-----|
| 1 | Platform account (register + email OTP) | **Yes** | Getting started |
| 2 | Privacy acceptance | **Yes** | Getting started |
| 3 | **Security database** (PostgreSQL recommended) | **Yes** for assets/scans | Security database |
| 4 | Dual-control users (operator + authorizer) | Strongly recommended | Users & approvals |
| 5 | First assets (domain / public GitHub) | Recommended | Daily activities |
| 6 | Client SMTP (your org’s alert email) | Optional but recommended | Email & SMTP |
| 7 | WhatsApp / Telegram | Optional | Alert channels |
| 8 | GitHub App | Optional | GitHub |
| 9 | Premium / AI Agent plan | When you need deep scans, PDF, private repos, public agent API | Plans |

> **Coming soon:** Phantix-hosted security databases. Until then, you connect your own PostgreSQL (or compatible) instance. See [02-security-database.md](./02-security-database.md).
