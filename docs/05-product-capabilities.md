## AI that stays accountable

| Capability | Description |
|------------|-------------|
| Finding explanation | Plain-language narrative from evidence |
| Executive summary assist | Board tone, evidence-bound |
| Domain agents | SOC, GRC, VAPT, threat intel, asset — **on-demand** |
| Skill library | Successful work can become reusable playbooks (anonymized before sharing patterns) |
| Governance | PII redaction, budgets, human review, audit of AI actions |
| **Public API** | **Paid AI Agent plan only** — programmatic agent access for integrators; not a full-engine public API SKU |

**Principle:** AI plans and explains. Engines discover and measure. Reports stay honest.

**Commercial note:** Platform Free/Premium cover the app. The **only public API payment plan** is AI Agent access.
